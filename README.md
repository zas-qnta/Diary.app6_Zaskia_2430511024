# 📖 Catatan Harian (Diary App)

Hai! Ini adalah aplikasi buku harian digital yang aku buat pakai **React Native**, **Expo**, dan **TypeScript**. Aplikasi ini ngebantu banget buat nyatet kegiatan sehari-hari, nyimpen momen seru, dan ngerapiin cerita hidup langsung dari genggaman tangan.

## ✨ Fitur Keren di Dalamnya:

* **Tulis & Kelola Catatan**: Bisa nambahin cerita baru, lihat daftar diary, sampai hapus catatan yang udah nggak kepake.
* **Pencarian Cepat**: Mau nyari kenangan lama? Tinggal ketik aja kata kuponya di kolom *search*, langsung ketemu!
* **Filter Berdasarkan Mood**: Ada pilihan emoji suasana hati (*😊, 🚀, ☕, ✨*) biar kita bisa nyaring catatan sesuai *vibe* hari itu.
* **Tanda Suka (Favorites)**: Suka banget sama satu cerita? Tinggal tap tombol *like* biar masuk ke tab khusus favorit.
* **Tampilan Nyaman**: Pakai konsep desain *Ocean Blue* yang adem, rapi, dan enak dilihat berlama-lama.

## 🛠️ Teknologi yang Digunakan:

* **Framework**: React Native & Expo Router
* **Bahasa**: TypeScript
* **State Management**: React Context (`DiaryContext`)
* **Styling**: Kumpulan token kustom (`COLORS`, `SPACE`, `RADIUS`, `TYPO`)
